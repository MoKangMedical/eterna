# 念念 Eterna 落地商业模式与小红书 / 抖音 / 数字人宣传作战包

版本：2026-05-28

## 1. 一句话定位

念念不是“复活亲人”的噱头产品，而是一套面向家庭的数字纪念与数字家人搭建服务：用课程化流程帮助用户整理亲人的文字、语音、照片、视频和 3D 素材，形成可对话、可回听、可回看、可主动问候的数字家人。

对外传播口径：

- 主张：不是替代，是陪伴。不是虚拟，是延续。
- 场景：当一句“我想你了”没人回应时，念念把声音、样子和共同回忆安放到一个可持续更新的家庭纪念册里。
- 产品锚点：数字人控制台、素材管理、语音 / 视频陪伴、主动联系、家庭追思册。
- 合规底线：所有 AI 生成内容必须显著标识；亲人声音、照片、视频、3D 素材必须有合法授权；宣传不使用“复活”“真实本人”等误导性表述。

## 2. 商业模式落地

### 阶段一：先跑通 DTC 付费闭环

目标：验证用户是否愿意为“更完整的亲人数字档案”持续付费。

产品包：

| 产品包 | 核心权益 | 目标用户 | 建议价格 |
|---|---|---|---|
| 初念体验 | 1 位亲人档案、文字回忆、基础对话、素材完整度评估 | 第一次尝试的用户 | 免费 / 低价体验 |
| 声音留存 | 语音素材上传、声音画像、语音陪伴、声音相册 | 最在意声音的家庭 | 年付 99-299 元 |
| 影像陪伴 | 照片 / 视频素材、视频陪伴、回忆短片、生成历史回看 | 希望“看见”的家庭 | 年付 399-699 元 |
| 家庭传承 | 多位亲人、家族相册墙、主动问候、电话桥接、多人管理 | 家庭共同维护 | 年付 999 元起 |
| 定制服务 | 3D 重建、老照片整理、口述史采集、上门影像整理合作 | 高净值 / 强需求家庭 | 项目制报价 |

关键闭环：

1. 用户从小红书 / 抖音进入官网。
2. 创建第一位亲人档案。
3. 上传至少 1 段语音、3 张照片、1 段回忆。
4. 生成第一次文字 / 语音 / 视频陪伴。
5. 邀请家庭成员补充素材。
6. 订阅声音、影像或家庭传承方案。

### 阶段二：内容获客 + 私域转化

内容不直接卖功能，先卖“整理亲人记忆的方法”。

转化路径：

- 小红书：故事笔记 / 操作清单 / 家庭相册墙案例 -> 官网搭建课 -> 微信私域咨询。
- 抖音：15-45 秒情绪短视频 / 数字人讲解 / 功能演示 -> 官网体验 -> 表单留资。
- 微信私域：7 天数字家人搭建营 -> 素材收集 -> 首次生成 -> 订阅。

### 阶段三：B2B2C 渠道放大

适合合作的渠道：

- 家庭影像整理工作室：照片修复、旧相册数字化、家庭录像转码。
- 纪念服务机构：以“数字纪念册 / 家庭口述史”作为增值服务。
- 养老服务机构：面向子女的“父母声音与人生故事留存”。
- 心理支持与哀伤陪伴机构：只做纪念整理，不替代心理治疗。
- 家族办公室 / 高端家庭服务顾问：高客单定制项目。

渠道分成建议：

- SaaS 订阅：首年 20%-35% 渠道佣金。
- 定制项目：按交付毛利 15%-30% 分成。
- 影像整理合作：按素材整理服务单独报价，念念收取平台与 AI 生成服务费。

## 3. 小红书打法

小红书适合“搜索 + 种草 + 情绪共鸣”。重点不是炫技，而是真实、克制、有方法。

账号定位：

- 账号名建议：念念 Eterna / 念念数字纪念册 / 念念家人档案馆。
- 人设：家庭记忆整理师 + 数字人搭建课讲解员。
- 内容语气：温柔、克制、实用，不卖惨，不制造焦虑。

核心栏目：

| 栏目 | 目标 | 内容形式 |
|---|---|---|
| 家庭记忆整理课 | 教用户开始整理素材 | 图文清单、便签卡、课程步骤 |
| 一句话声音留存 | 放大语音价值 | 30 秒口述脚本、声音素材示例 |
| 旧照片会说话 | 展示照片 / 视频价值 | 老照片相纸墙、短视频 Demo |
| 数字人控制台拆解 | 建立产品信任 | 控制台截图、人格卡、片段库 |
| 伦理与授权 | 降低顾虑 | 合规说明、授权清单、隐私保护 |

首月发布节奏：

- 每周 5 篇图文笔记。
- 每周 2 条短视频笔记。
- 每周 1 篇“用户故事型长笔记”。
- 每天固定回复评论，沉淀 20 个高频问题到 FAQ。

小红书首批标题：

1. 我终于知道，该怎么整理爸爸留下的声音了
2. 想做亲人的数字纪念册，第一步不是上传照片
3. 30 秒讲完一个人：数字家人素材采集脚本
4. 旧照片、语音和口头禅，怎么变成一个人格卡
5. 我们做数字人，但绝不说“复活亲人”
6. 给妈妈建一页会回应的家庭追思册
7. 如果只剩一段录音，还能留下什么
8. 数字人控制台长什么样：人格卡、声音画像、视觉画像
9. 家庭相册墙：把散落的照片重新挂起来
10. 清明、中秋、生日，纪念可以怎样回到日常
11. 做数字亲人前，这 5 个授权问题必须想清楚
12. 一套给全家的数字家人搭建课

推荐关键词：

- 亲人离世、想念爸爸、想念妈妈、家庭相册、旧照片修复、声音留存、数字纪念册、AI 纪念、数字人、家庭回忆、口述史、亲人语音、追思册。

## 4. 抖音打法

抖音适合“强开头 + 情绪场景 + 产品演示”。视频要短，前 3 秒必须让用户知道为什么要看下去。

账号定位：

- 数字人讲解员：由品牌虚拟讲解员出镜，明确标注“AI 数字人 / AI 配音 / 演示内容”。
- 产品场景号：以真实 UI 演示和用户故事为主，不制造灵异感。

视频结构模板：

1. 0-3 秒：情绪钩子。
2. 3-10 秒：具体场景。
3. 10-25 秒：产品动作。
4. 25-35 秒：结果展示。
5. 35-45 秒：行动号召。

首批短视频脚本：

| 编号 | 开头钩子 | 中段演示 | CTA |
|---|---|---|---|
| D01 | “如果还有一次机会，你最想听 ta 说什么？” | 展示语音素材上传与声音画像 | 进入官网，先建一位亲人档案 |
| D02 | “亲人留下的照片，不该只躺在相册里。” | 相册墙、视觉画像、回忆片段 | 上传 3 张照片，生成第一张纪念卡 |
| D03 | “数字人不是复活，是把关系里的回应感保存下来。” | 人格卡 + 片段库 | 看看念念如何搭建数字家人 |
| D04 | “只剩 30 秒录音，还能做什么？” | 声音画像进度条 | 用 30 秒开始声音留存 |
| D05 | “生日那天，如果能收到一句熟悉的祝福。” | 主动联系设置 | 体验生日 / 节日主动问候 |
| D06 | “别急着上传素材，先讲一段你们的故事。” | 语音录入自动填人格卡 | 跟着搭建课一步步做 |
| D07 | “给全家做一本会回应的追思册。” | 家庭相册墙 + 多人档案 | 邀请家人一起补回忆 |
| D08 | “我们为什么不说‘复活亲人’？” | 合规与授权卡 | 了解念念的边界和保护 |

抖音发布节奏：

- 每天 1 条 15-45 秒短视频。
- 每 3 天复盘完播率、3 秒留存、评论关键词。
- 每周保留 2 条效果最好的视频做投放加热。
- 所有 AI 数字人 / AI 配音视频统一加显著标识。

## 5. 数字人宣传模式

数字人宣传不使用真实逝者肖像作为广告主角，优先使用品牌虚拟讲解员“念念引导员”。

念念引导员设定：

- 角色：数字家人搭建课讲解员。
- 视觉：温暖、克制、非真人误导，避免过度拟真。
- 声音：稳定、清晰、低情绪冲击，明确为 AI 配音。
- 职责：讲解如何采集素材、如何授权、如何建立人格卡、如何开启主动陪伴。

数字人视频栏目：

1. 60 秒讲清：数字人控制台有什么。
2. 30 秒作业：今天请上传三张最能代表 ta 的照片。
3. 1 分钟答疑：只有照片，没有声音怎么办。
4. 合规课堂：为什么必须获得家属授权。
5. 案例演示：一段口述如何自动填入人格卡。

统一片尾：

> 这是一段 AI 数字人讲解内容。念念只在获得授权的前提下整理语音、照片、视频和回忆。不是替代，是陪伴。不是虚拟，是延续。

## 7. 关键指标

北极星指标：

- 每个家庭的“数字人完整度 × 30 天回访次数”。

渠道指标：

- 小红书：收藏率、搜索进站、私信咨询、评论问题密度。
- 抖音：3 秒留存、完播率、主页点击率、官网点击率。
- 官网：创建档案率、素材上传率、首次生成率、家庭成员邀请率。
- 私域：7 天搭建营完成率、付费咨询率、订阅转化率。

业务判断阈值：

- 访问到创建档案 ≥ 8%。
- 创建档案到上传素材 ≥ 45%。
- 上传素材到首次生成 ≥ 60%。
- 首次生成到订阅意向 ≥ 8%。

## 8. 合规与平台发布检查

发布前必须检查：

- 是否显著标注 AI 生成、AI 数字人、AI 配音或演示内容。
- 是否避免“复活亲人”“本人真实回应”等误导性表达。
- 是否取得素材授权。
- 是否避免展示用户真实隐私信息。
- 是否避免使用未授权音乐、影视片段、名人声音或他人肖像。
- 是否提供心理健康边界说明，不把产品包装成心理治疗。
- 是否保留素材来源、生成记录、授权状态和发布记录。

依据：

- 《人工智能生成合成内容标识办法》已要求文本、音频、图片、视频、虚拟场景等生成合成内容进行显式和隐式标识，并于 2025-09-01 起施行。
- 《互联网信息服务深度合成管理规定》要求深度合成服务在合理位置进行显著标识，避免公众混淆或误认。
- 小红书商业化公开页面强调“种草、口碑管理、站内闭环”等经营路径，适合念念先做真实故事和信任沉淀。
- 巨量引擎公开页面强调通过抖音生态将内容创造力转化为生意驱动力，适合念念做短视频场景演示和投放测试。
